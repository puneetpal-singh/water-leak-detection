# Dashboard direction

Applied /unslop by [Damir Sokolovsky](https://github.com/heydamir/unslop), CC BY 4.0.

This is a new screen, so there is no existing interface to audit. The design review
will check the rendered screen for the skill's signs: decorative gradients,
unverified figures, equal panels with repeated charts, cramped controls and weak hierarchy.

- Product: inspect water-network sensors and assess new-leak alarms on BattLeDIM.
- Character: measured, technical, candid.
- World: water utility instruments and an engineer's investigation log.
- Moments: a large pressure trace with an onset marker; the real EPANET network.
- Signature: the same vertical onset marker links traces, scores and event details.

Pass order: spacing, color, icons, copy, type, layout, details, visuals, motion.
Use a 4 px spacing grid; neutral surfaces; teal measurements and amber onset markers;
Segoe UI with Consolas figures; no decorative icons or animation. Let one main chart
lead each view. Label the retrospective study and 72-hour onset task explicitly.
